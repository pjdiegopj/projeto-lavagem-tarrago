# LavaCar Tarrago

Projeto de demonstração para uma empresa de lavagem de carros (LavaCar Tarrago).

Descrição
- Este projeto representa o site de uma lavagem de carros, com páginas para apresentar serviços, preços e contato.

Como usar
- Abra [lavacar-tarrago/index.html](lavacar-tarrago/index.html#L1) no navegador para ver a página inicial.

Conteúdo principal
- `index.html`: página inicial com informações sobre os serviços.
- `src/css/`: estilos do site (`reset.css`, `responsivo.css`, `style.css`).
- `src/js/`: scripts principais (se aplicável).
- `imagens/`: fotos e ícones usados no site.

Serviços (exemplo)
- Lavagem externa
- Lavagem completa (interna + externa)
- Polimento e enceramento
- Higienização interna

Estrutura do projeto

- lavacar-tarrago/
  - index.html
  - src/
    - css/
    - js/
    - imagens/
